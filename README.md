# Ecommerce (Nextjs / Nodejs)

This is an eCommerce project built using Next.js and Node.js. It includes essential eCommerce functions such as browsing products, ordering products, and facilitating online payments. Additionally, there is an admin panel for managing the platform.

# Demo

# Runing This Project
To install this project, you should have Node.js.
## Feature of the Project

 * Users
    * Authentication Jwt/Google-OAuth
    * Cart Page 
    * WishList
    * Banner Ads
    * Popular products
    * Search Products / Brows Products with different filter
    * Online payments
    * Order Products / track Orders / Download Invoice
    * Review Products / Rate the Products
* Admin 
   * Analytics and Reports
   * User Management
   * Order/Transaction Management
   * Product/Content Management


## Frontend installation (Nextjs)

 Clone this Project 
```
https://github.com/Mahammed-Siyabuddeen/ecommerce-nextjs
```
 Go to the directory and install the package dependency.
 ```
 npm install 
 ```
 #### Create an env file. Please refer to the example.env file.

Run the Frontend in Developer Mode

```
npm run dev
```
Run in Production Mode
```
npm run build
npm start
```
#### Now your is Nextjs Running in 3000 port

**Database:** MongoDB
